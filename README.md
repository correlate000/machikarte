# machikarte

議会コモンズの公開資料と、地方議会の記録を再利用するためのコード・仕様・サンプルを置くリポジトリです。

議会コモンズは、発言・原典・引用・再利用の基盤です。構想0区は、まちの状況と暮らしの課題、政策の経緯を出典とともに読む入口です。両者の役割を分けて整備します。

## 手元で試す

Python3の標準機能だけで、固定した公開用メタデータから日進市の収録範囲を読み取れます。リポジトリのルートで実行してください。

```sh
python3 reuse-kit/inspect_coverage.py --code 232301
```

この例は通信、データベース照会、AIモデルを使いません。自治体名、数値の基準日、収録年の端点、版、欠測や条件の読み方をJSONで返します。会議録本文の検索や、質問に答えるRAGの例ではありません。

[説明と必要ファイル](reuse-kit/README.txt)と、[固定版の一覧・指紋](reuse-kit/examples/commons-snapshot/manifest.json)をあわせて確認してください。指紋はファイル内容が一致するかを確かめる計算値です。数値の生成日と、対象年・基準日は区別します。

## このリポジトリの資料

- `reuse-kit/`：収録範囲を通信なしで読む最小例。
- `docs/`：形式や方法を説明する資料。
- `aggregation-queries/`：集計クエリ。
- `sample-data/`：説明用のサンプル。

各資料の対象期間・版・利用条件を確認して使ってください。収録年の端点、保存件数、一部の照合だけで、全期間・全会議の収録や本文品質を保証するものではありません。全国の取得・照合状況は[STATUS.md](STATUS.md)で、同じ会議一覧を分母にできるかも含めて示します。

議会コモンズの案内：[gikai-commons.isvd.or.jp](https://gikai-commons.isvd.or.jp/)。まちを調べる入口：[構想0区](https://kousou0.isvd.or.jp/)。このリポジトリの資料と、各サイトや個別配布版の条件は区別してください。

## 出典とID

引用や訂正では、対象の会議・日付、資料の版、項目名とID、原典の該当箇所を残します。取得経路によって既存IDの区切り数は異なり、利用者側で区切りを削る等の変換はしません。

この最小例が読むのは収録範囲のメタデータです。同梱するID仕様は固定した時点のドラフトで、現行ルートの入力判定との整合は別に確認が必要です。詳しくは[IDの注意](reuse-kit/ID-NOTE.txt)を参照してください。
