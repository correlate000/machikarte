# Tier 分類

machikarte が各自治体の議事録カバレッジを評価する 5 段階分類。

## L4: full coverage

- 議事録全期間が機械可読形式（HTML / 検索可能 PDF）で公開されている
- machikarte で全期間取得済み
- 議員別・年度別・テーマ別の検索がフル機能で動作する

該当自治体例: 多くの政令市・中核市・特別区など、議事録検索システム（kaigiroku.net / discuss vision 等）導入自治体。

## L3: PDF / HTML 一部

- 議事録は公開されているが、OCR 必要 PDF や独自形式で機械可読性が部分的
- 一部期間のみ取得済み、または OCR 品質に制約あり
- 検索結果に欠落・誤読が混入する可能性

該当例: 中小規模自治体、PDF 議事録を公式サイトに直置きしている自治体。

## L2: newsletter のみ

- フル議事録は非公開、議会だより（広報誌）に主要発言が要約掲載
- machikarte は議会だより PDF を OCR して取得
- 議員別追跡は可能だが、発言全文ではなく要約

該当例: 小規模町村、議事録公開が議会だより止まりの自治体。

## L1: 部分取得

- 議事録は一部だけ取得済み（年度の歯抜け / カテゴリの抜け）
- カバレッジ完成が β 期間の課題

## L0: 議事録非公開確定

- machikarte 取得時点で公開議事録 / 議会だより / 動画字幕いずれも存在を確認できなかった自治体
- audit ノートで以下 5 手段の試行を記録:
  1. depth-3 サイト内 anchor crawl
  2. 検索 CGI（`mt-search.cgi` 等）への直接アクセス
  3. WebSearch（`site:{domain} filetype:pdf`）
  4. sitemap.xml 確認
  5. Wayback Machine 確認
- 上記すべて結果ゼロの自治体のみ L0 確定

L0 判定は **5 手段すべての試行履歴を audit_note フィールドに記録** することで透明性を担保。
誤分類が発覚した場合は data correction issue で報告してください。

## 各 Tier の運用

| Tier | β 期間（〜 2026-08-15） | 正式版以降 |
|---|---|---|
| L4 | 機能フル提供 | 議員カルテ正式リリース |
| L3 | 検索機能のみ、OCR 改善継続 | 議員カルテ機能（要 verify） |
| L2 | 議会だより検索のみ | newsletter 専用 UI |
| L1 | 部分検索、欠落明示 | 取得継続 |
| L0 | 「議事録非公開確定」表示 | 再 audit 継続 |

## 透明性方針

- 各自治体の現在 Tier は β サイト上で確認可能
- Tier 変更履歴は audit_note + audited_at + audited_by の 3 フィールドで記録
- L0 → L2/L3 へ昇格時は audit ログを添付
